# Редизайн «Штурмана»: план по пунктам

Решения владельца:
- основа во всех темах — «Жидкое стекло» (вариант 1 со страницы вариантов);
- карта — как в варианте 4 (сильный наклон в поездке, объёмные дома), с выключателем «3D-карта» в настройках (по умолчанию включено);
- особенности тем: Классика и Street — неон (вариант 2); NASCAR, GT и Rally — телеметрия (вариант 3);
  Night Rider и Drift — глубина 3D (вариант 4); Принцесса — чистое стекло с сердечками.
- логику экранов, голос, звуки и заставки не трогать.

Правило для каждого пункта: после изменений проверить себя (сборка и тесты в CI, перечитать изменённый код на ошибки: падения, неверные отступы, наложения элементов, лишние перерисовки) и исправлять, пока ошибок не останется. Пункт не отмечается, пока сборка не зелёная.

Запуски: 05:41 по Москве — основной; 10:41 — запасной, если к нему не всё готово.
Если папки с репозиторием нет (контейнер пересоздан): `git clone https://github.com/stwile8-sys/shturman && git checkout night`,
затем `git config --add remote.origin.fetch '+refs/heads/night:refs/remotes/origin/night'`.
Ошибки сборки: `git fetch origin '+refs/heads/buildlog:refs/remotes/origin/buildlog' && git show origin/buildlog:errors.txt`
(смотреть строки `e: `; лог свежий, только если последний запуск упал).

Каждый пункт — отдельный заход: сделать, собрать на ветке `night` (CI), исправить ошибки, отметить здесь `[x]`, закоммитить.
