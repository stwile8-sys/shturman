# Штурман

Личный навигатор для Android, который «думает как таксист»: маршруты считаются прямо на телефоне (Valhalla, офлайн),
карта на OpenStreetMap (MapLibre). Область по умолчанию — Псковская область.

## Что умеет
- Несколько вариантов маршрута: самый быстрый, «Без камер», «Ровный ход», «Экономия бензина», с расходом и стоимостью.
- Голосовые подсказки (записанные заранее, работают без синтезатора речи), раллийный «дорожник» по изгибам дороги.
- Съезд с маршрута: пересчёт, разворот, пропущенный поворот, движение назад. Чувствительность настраивается.
- 8 тем оформления, у каждой свои заставка, звуки и анимации.
- Общая база (Firebase): дорожные данные друзей, вход через Google, коды активации.
- Проверка обновлений при запуске.

## Сборка
Сборка идёт в GitHub Actions (`.github/workflows/build.yml`): тесты, затем APK. Push в `main` создаёт релиз `build-N`.
Локально: `gradle :app:testDebugUnitTest :app:assembleDebug`.

## Структура
- `app/src/main/java/ru/shturman/routing` — маршруты, геометрия, съезд с маршрута (`Deviation.kt`), сеть (`Net.kt`).
- `app/src/main/java/ru/shturman/ui` — экраны и темы (`ui/themes`).
- `app/src/test` — юнит-тесты (расчёт, топливо, повороты, детектор съезда, повторы сети).

## Ограничения
- Камеры не рисуются на карте, но учитываются в варианте «Без камер».
- Логика каравана при съезде одного из участников не реализована.
